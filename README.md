# 人狼ゲーム 進行アプリ

集まってワイワイ遊ぶ用の、対面人狼ゲーム進行アプリ。

## 使い方

1. GMがブラウザで本アプリを開く
2. ゲーム開始 → 人数選択 → 役職構成 → 配役
3. 各プレイヤーにQRコードを配って役職を確認してもらう
4. GM台本に従ってゲーム進行
5. 死亡通知・占い結果はFirebase経由で各プレイヤーのスマホへ自動配信

## 構成

- `index.html` — アプリ本体（1ファイル完結）
- `qrcode.js` — QRコード生成ライブラリ（オフライン）
- バックエンド：Firebase Realtime Database
- デプロイ：Vercel

## 機能

- 配役（標準6役職：村人・人狼・占い師・騎士・霊媒師・狂人）
- 配布2モード（各自スマホQR / 1台で回す）
- GM台本（夜・朝・昼の進行ガイド）
- 死亡通知・占い結果・霊媒結果の本人スマホへの自動配信
- 勝敗判定と結果画面
- ルールブック（役職の能力＋初心者向け使い方）
- プレイヤー名登録（任意）
